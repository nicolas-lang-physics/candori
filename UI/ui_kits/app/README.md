# Candori app — UI kit
The four MVP screens from the Phase 0 brief, as an interactive click-through (mobile-first, 390px column):
1. Home / Streak — calm landing, quiet streak, one CTA
2. Lesson — philosophy provocation card
3. Word Association — AI turn-taking with soft timer + glow
4. One-Word Story — alternating words, living story, share state
Reflection closes the session. AI turns are simulated with canned words. Glow heat is driven by real typing cadence.
